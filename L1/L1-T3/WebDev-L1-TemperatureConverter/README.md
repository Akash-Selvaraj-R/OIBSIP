# THERMA — Temperature Converter

A clean, responsive temperature conversion web application built as part of the **OASIS INFOBYTE Web Development & Designing** internship program.

## Objective

THERMA is a polished utility that converts temperatures instantly between Celsius, Fahrenheit, and Kelvin. It was developed as the Level 1, Task 3 submission for the OASIS INFOBYTE Web Development & Designing internship.

## Features

- **Three-unit conversion** — Celsius, Fahrenheit, and Kelvin
- **Numeric validation** — Rejects non-numeric and empty input
- **Absolute-zero validation** — Prevents physically impossible temperatures
- **Simultaneous results** — Displays all three converted values at once
- **Responsive design** — Works on desktop, tablet, and mobile
- **Accessible controls** — Semantic HTML, proper labels, keyboard navigation
- **Clean interface** — Minimal, professional design with strong typography

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius → Fahrenheit | °F = (°C × 9/5) + 32 |
| Fahrenheit → Celsius | °C = (°F − 32) × 5/9 |
| Celsius → Kelvin | K = °C + 273.15 |
| Kelvin → Celsius | °C = K − 273.15 |

## How to Run

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Enter a temperature, select its unit, and click **Convert Temperature**

No server or build tools required.
