# Akash Selvaraj R — Personal Portfolio

A modern, responsive personal portfolio website built as part of the **OASIS INFOBYTE Web Development & Designing — Level 1 Task 2** internship.

## Objective

This project demonstrates proficiency in HTML5, CSS3, and vanilla JavaScript by building a professional personal portfolio. It showcases skills, projects, and contact information in a clean, dark-themed interface optimized for all device sizes.

## Features

- Responsive design — works on desktop, laptop, tablet, and mobile
- Sticky navigation bar with smooth scrolling
- Mobile hamburger menu with overlay
- Active navigation state tracking on scroll
- Hero section with profile placeholder and CTAs
- About Me section
- Visual skills grid organized by category
- Project showcase with technology tags and GitHub links
- Contact section with LinkedIn and GitHub links
- Accessible semantic HTML structure
- CSS custom properties for consistent theming
- Reduced motion support for accessibility

## Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
- Vanilla JavaScript
- Google Fonts (Inter)

## How to Run

1. Clone or download the project files
2. Open `index.html` in any modern web browser

No build tools, server, or dependencies required.

Alternatively, serve with a local server:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000`.
