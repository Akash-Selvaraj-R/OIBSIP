## 📌 About OIBSIP

The OASIS INFOBYTE internship provides practical development tasks designed to strengthen technical skills through hands-on project implementation.

For the **Web Development & Designing** track, the official task structure contains three levels:

| Level   | Tasks | Focus                                     |
| ------- | ----: | ----------------------------------------- |
| Level 1 |     3 | HTML5, CSS3, foundational web development |
| Level 2 |     4 | Interactive frontend applications         |
| Level 3 |     1 | Full-stack application development        |

The official requirements state that a participant completes **all tasks within one chosen level** for the Web Development & Designing track. Level 3 is the advanced full-stack option requiring backend and database knowledge.

# 📹 Demo & Submission

OIBSIP requires a demonstration video for practical tasks.

The prescribed workflow includes:

1. Review the task requirements
2. Build the project
3. Push the completed project to the `OIBSIP` GitHub repository
4. Record a functional demo
5. Post/link the demo on LinkedIn
6. Tag OASIS INFOBYTE
7. Include `#oasisinfobyte`
8. Complete the required peer evaluation
9. Submit the OIBSIP repository link through the official submission form

The required video title card should display:

```text
Full Name
Track
Task Title
```

for the opening 2 seconds of the demonstration video.
